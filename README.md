# Faruq Ayomide Ojolowo

Personal website for Faruq Ayomide Ojolowo — Founder & CEO of Apex Universal Studios™.

Building an enduring ecosystem across entertainment, media, technology, and intellectual property.

**Visit:** https://faruqayomideojolowo.github.io

## About

This is a single-page website built with semantic HTML, CSS, and vanilla JavaScript. It includes:
- Editorial design with serif typography
- Smooth scroll animations and parallax effects
- Schema.org identity graph
- Mobile responsive
